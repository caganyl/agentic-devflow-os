# Mimari Profil

Bu klasör projenin onaylı mimari profilini tutar:
`ARCHITECTURE_PROFILE.md` (okunur özet ve konvansiyonlar) ve
`architecture-profile.json` (tarayıcının kontrol ettiği kurallar).

`architecture-analyst` taslak yazar; yalnızca insan `confirmed` yapar.
Onaylı profil ajanlar için dondurulmuştur
(`.claude/hooks/enforce-role-boundaries.sh`, architecture profile gate).
