taşır. Bu schema canonical `MCP_AUDIT_EVENT_CONTRACT.md` şeması değildir.

| Alan | Tip | Değer Aralığı |
|---|---|---|
| `evidence_schema_version` | sabit | — |
| `evidence_id` | random local referans | Disposable workspace'e özgü; session_id/tool_use_id'den türetilmez |
| `timestamp` | ISO-8601 UTC | — |
| `hook_event` | sabit enum | `PreToolUse` |
| `tool_class` | sabit enum | `builtin_read` |
| `test_path` | kapalı enum | `writer_available` \| `writer_unavailable` |

token, credential, secret, session ID, tool use ID, reason, exception text
veya serbest metin alanı.

### Multiple Invocation Gözlemi

Failure path'te 2 adet control evidence record gözlemlendi. Bu gözlem,
PreToolUse hook'unun birden fazla kez tetiklendiğini gösterir.

> **REQ-002 spike'ı exactly-once hook delivery garantisi iddia etmez.**
> Bu gözlem, hook mekanizmasının multiple invocation üretebileceğinin
> kaydedilmesidir; bu davranış bir bloker olarak değil, scope açıklığı
> olarak not edilir. Exactly-once delivery tasarımı bu spike'ın kapsamı
> dışındadır.

## Bilinen Sınırlar

1. **Non-canonical evidence gerçek MCP audit event değildir.** Bu spike
   built-in `Read` tool için 7 alanlı sanitised evidence üretmiştir; bu
   kayıt canonical `MCP_AUDIT_EVENT_CONTRACT.md` kapsamındaki 15 alanlı
   MCP audit event doğrulaması değildir ve bu iddiayı taşımaz.

2. **Exactly-once hook delivery garantisi yoktur.** Failure path'te 2
   control evidence record gözlemlendi; bu, multiple PreToolUse invocation
   olduğunu gösterir. Exactly-once semantik bu spike'ın kapsamı dışındadır.

3. **Tam host izolasyonu sağlanmadı.** `/status` ekranında User settings
   ve Project local settings kaynakları görünüyordu. Bu spike "hiçbir
   kullanıcı ayarı yüklenmedi" veya "tam host izolasyonu sağlandı" iddiası
   taşımaz.

4. **Global network yokluğu iddiası yok.** Bu spike hook kapsamında MCP
   veya harici dispatch başlatılmadığını kaydeder; genel network
   erişilebilirliği hakkında iddia taşımaz.

5. **H4 düşük öncelikli test-only follow-up açık.** REQ-001 handoff'unda
   (`docs/handoffs/REQ-001.md`) belirtilen H4 `agent_type` extraction
   asimetrisi (audit-unavailable ve unclassified identity yolları) bu spike
   kapsamında kapatılmamıştır; test-only iyileştirme adayı olarak açık
   kalmaktadır.

  tetiklenebildiği.
- Fail-closed davranışının (audit writer unavailable → PreToolUse deny)
  disposable local ortamda gözlemlenebildiği.
- Non-canonical 7 alanlı sanitised evidence record'ın üretilebildiği.

REQ-002 spike'ının **kanıtlamadığı**:

- Canonical MCP audit contract doğrulaması.
- Production audit enforcement kapasitesi.
- Gerçek MCP bağlantısı için herhangi bir No-Go kapısının kapatılması.
- Exactly-once hook delivery.
- Tam host izolasyonu.

Gerçek MCP bağlantısı için aşağıdakiler **ayrı insan onayı gerektirir:**

- Audit logging mekanizmasının çalışır biçimde implemente edilmesi ve
  doğrulanması.
- Her MCP için capability validation ve environment-specific smoke test.
- Credential storage yönteminin insan maintainer tarafından onaylanması.
- Audit sink'in append-only veya tamper-evident olduğunun doğrulanması.
- Audit writer'ın out-of-band ve non-recursive olduğunun doğrulanması.
- Ayrı, açık bir insan maintainer onayının kaydedilmesi.

Bu kapıların tamamı kapatılmadan hiçbir agent veya insan gerçek bir
MCP sunucusuna bağlanamaz.
