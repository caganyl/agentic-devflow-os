# Agent Roster

Bu dosya Agentic DevFlow OS içindeki standart rolleri listeler.

- Delivery Lead — planlama, iş dağıtımı, quality gate ve handoff
- Product Analyst — PRD, requirement, acceptance criteria
- Solution Architect — ADR, mimari seçenekler, trade-off
- Contract Broker — OpenAPI, event, database ve shared type sözleşmeleri
- Frontend Engineer — product UI ve frontend testleri
- Backend Engineer — API, auth, service ve business logic
- Database Engineer — schema, migration, index ve rollback
- AI/Data Engineer — LLM, RAG, ML, data pipeline
- QA Automation — unit, integration, E2E ve browser testleri
- Security Red Team — threat model ve adversarial review
- Design Reviewer — UX, accessibility, visual quality ve motion
- EvalOps Reviewer — golden dataset, regression, latency ve cost evaluation
- Integration/Release — integration branch, CI, scorecard ve PR hazırlığı

Her role ait gerçek agent tanımı daha sonra `.claude/agents/` altında bulunacaktır.
